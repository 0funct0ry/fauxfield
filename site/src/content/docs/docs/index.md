title: Fauxfield documentation
description: Guides and reference for Fauxfield, the local-first mock API tool.
---

Fauxfield is a mock API tool whose Workspace is a folder of TOML files. The desktop app, the
`fauxfield` command, the headless runner and the MCP server all read and write those files.

- **New here?** [Install](/docs/getting-started/install/), then [make your first mock](/docs/getting-started/first-mock/).
- **Looking for a feature?** The guides cover [Routes](/docs/guides/routes/),
  [templating](/docs/guides/templating/), [Datasets](/docs/guides/datasets-and-crud/),
  [proxying and recording](/docs/guides/proxy-and-recording/), [WebSockets](/docs/guides/websockets/),
  [callbacks](/docs/guides/callbacks/), [CI](/docs/guides/ci/) and [agents](/docs/guides/agents/).
- **Need exact keys or flags?** The [server file](/docs/reference/server-file/),
  [CLI](/docs/reference/cli/) and [MCP tools](/docs/reference/mcp-tools/) references are generated from
  the code, so they match the version you run.
- **Copy a setup:** [Recipes](/docs/recipes/).
